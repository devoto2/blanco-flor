Política de privacidad

Última actualización: 11 de octubre de 2026

Esta política describe cómo la aplicación Blanco Flor Ads, de la florería Blanco Flor (Av. Corrientes 1186, Ciudad Autónoma de Buenos Aires), trata la información.

Qué hace la aplicación

Blanco Flor Ads es una herramienta de uso interno. Usa la API de Google Ads únicamente para consultar y administrar la cuenta publicitaria propia del negocio Blanco Flor (por ejemplo, ver resultados de campañas y preparar informes). No está disponible para el público ni para otros anunciantes.

Qué datos usa

Al autorizar la aplicación con una cuenta de Google, se accede solo a los datos de la cuenta de Google Ads del negocio (campañas, anuncios, presupuestos y métricas), mediante el permiso https://www.googleapis.com/auth/adwords. La aplicación no recolecta datos de terceros, ni de clientes de la florería, ni de visitantes de este sitio.

Uso y conservación

La información se usa exclusivamente para gestionar la publicidad de Blanco Flor. No se vende, no se cede ni se comparte con terceros, y no se usa para publicidad dirigida a personas. Las credenciales de acceso se guardan de forma privada y pueden revocarse en cualquier momento desde la configuración de la cuenta de Google.

Uso de datos de las APIs de Google

El uso de la información recibida de las APIs de Google cumple con la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.
